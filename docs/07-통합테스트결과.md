## A. 자동(adb) 검증 — 완료

| ID | 항목 | 결과 | 근거 |
|---|---|---|---|
| IT-MVP-01 | 공유(ACTION_SEND) 즉시 재생 | ✅ 통과 | state=PLAYING, 종료 버튼 존재, 크래시 0 |
| IT-MVP-02 | 링크(ACTION_VIEW)+타임스탬프 30초 | ✅ 통과 | position 36초부터 재생 |
| IT-EXT-02 | 없는/삭제 영상 예외 처리 | ✅ 통과 | 크래시 없이 처리 |
| IT-MVP-03 | 화면 끄기 직후 재생 유지 | ✅ 통과 | keyevent 26 후 state=PLAYING |
| IT-FUN-04 | 강제종료 후 재실행 대기열 복원 | ✅ 통과 | 재실행 시 state=NONE (자동재생 안 함) |
| — | 전반 크래시 | ✅ FATAL 0 | logcat 확인 ("Invalid ID"는 경미한 리소스 경고, 크래시 아님) |
| IT-WV(B) | 방식 B: 웹 영상 클릭 → 네이티브 상세화면 | ✅ 통과 | 영상 중복·웹 헤더 잔존 없음 (실기기 스크린샷 확인) |
