# 01. 요구사항 문서 — 유튜브 백그라운드 재생 앱 (가칭: UTub)

- 작성일: 2026-08-17
- 상태: **사용자 최종 승인 완료** (2026-08-17)
- 작성 방식: Claude·agy 독립 분석 → 비교·대조 → 순차 질의응답 → 사용자 승인

---

## 1. 목적

스마트폰 **화면이 꺼진 상태(잠금화면/AOD)나 백그라운드**에서도 유튜브 콘텐츠를 끊김 없이 재생하고 제어할 수 있는 **개인용 Android 앱**을 만든다. 사용감은 기존 유튜브 앱과 최대한 동일하게 하되, 구글 계정 로그인 없이 모든 개인화 기능을 앱 자체(로컬)에서 제공한다.

## 2. 대상 사용자

- 본인(개인용). 음악·강의·팟캐스트 등 음성 위주 콘텐츠를 화면을 끄고 듣거나, 다른 앱을 쓰면서 듣는 용도.

## 3. 배포 및 플랫폼

| 항목 | 확정 내용 |
|---|---|
| 플랫폼 | Android 전용 네이티브 |
| 개발 환경 | Windows 11 + Android Studio |
| 기술 스택(방향) | Kotlin + Jetpack Compose + AndroidX Media3(ExoPlayer) + NewPipeExtractor 계열 |
| 배포 | 개인용 APK 직접 설치(사이드로딩). 스토어 배포 안 함 |
| 지원 기기 | 갤럭시 S20 ~ 최신 기종 |
| OS 범위 | minSdk 28 (Android 9) / targetSdk 최신 — 통합테스트 기기(갤럭시 S8+, Android 9) 지원 위해 29→28 조정 (2026-08-17) |

## 4. 핵심 기능 요구사항

### 4.1 재생 (핵심)
- F-01 유튜브 영상/오디오 재생 (자체 플레이어, 공식 플레이어 미사용)
- F-02 **화면 꺼짐 상태에서 재생 유지** (Foreground Service + MediaSession)
- F-03 **백그라운드(다른 앱 사용 중) 재생 유지**
- F-04 잠금화면·상단 알림 미디어 컨트롤러 (재생/일시정지/이전/다음/탐색)
- F-05 블루투스 이어폰/헤드셋 버튼 제어
- F-06 **광고 없는 재생** (스트림 직접 추출 방식의 기본 특성)
- F-07 재생 대기열(Queue) 관리 및 연속 재생
- F-08 오디오 전용 모드 (영상 렌더링 생략, 데이터/배터리 절감)

### 4.2 탐색
- F-10 유튜브 검색 (자동완성 포함)
- F-11 홈 피드 (인기/급상승 등 비로그인 공개 피드)
- F-12 채널 페이지·연관 영상·공개 재생목록 탐색
- F-13 유튜브 앱/브라우저에서 "공유하기"로 링크 받기, 링크 붙여넣기 재생

### 4.3 개인화 — 전부 로컬 DB 자체 구현 (구글 로그인 없음)
- F-20 로컬 구독 + 구독 채널 새 영상 피드 (앱이 자동 갱신)
- F-21 시청 기록 (자동 기록, 검색/삭제)
- F-22 이어보기 (마지막 재생 위치 저장·복원)
- F-23 로컬 재생목록 (생성/편집/반복/셔플)
- F-24 나중에 보기 / 좋아요(즐겨찾기)
- F-25 검색 기록·최근 검색어
- F-26 재생 대기열 보존 (앱 재시작 후 복원)
- F-27 오프라인 저장 (오디오/영상 다운로드)
- F-28 배속·볼륨 설정 기억 (채널별)
- F-29 구간 북마크 (영상 내 특정 시점 저장)
- F-30 로컬 데이터 백업/복원 (파일 내보내기/가져오기)
- F-31 Google Takeout 파일 가져오기 (기존 계정 구독 목록 등 일회성 이전)

### 4.4 부가
- F-40 PIP(화면 속 화면) 모드
- F-41 SponsorBlock 연동 (영상 내 스폰서 구간 자동 건너뛰기)

## 5. 비기능 요구사항

- N-01 갤럭시 One UI 절전 정책 대응: 첫 실행 시 배터리 최적화 예외 요청 플로우 필수 (딥 슬립으로 재생 끊김 방지)
- N-02 Android 13+ 알림 권한(POST_NOTIFICATIONS) 및 FOREGROUND_SERVICE_MEDIA_PLAYBACK 대응
- N-03 유튜브 규격 변경 대비: 추출 라이브러리 교체/업데이트가 쉬운 구조로 분리 설계
- N-04 Takeout 대량 가져오기 시 요청 속도 제한(딜레이/배치) 처리 — IP 일시 차단(429) 방지
- N-05 UI/UX는 기존 유튜브 앱과 유사한 구성 (학습 비용 최소화)

## 6. 범위 제외 (하지 않는 것)

- 구글 계정 로그인 (WebView/쿠키 방식 포함) — 계정 정지 위험으로 배제
- 로그인 기반 개인 맞춤 추천 피드, 서버 반영 좋아요/댓글 작성/계정 구독 동기화
- Play 스토어 배포, 수익화(광고/유료)
- iOS 지원

## 7. 단계적 개발 로드맵 (사용자 동의)

| 단계 | 범위 |
|---|---|
| 1차 (MVP) | F-01~F-08, F-10, F-13 + N-01, N-02 (검색·광고 없는 재생·백그라운드/화면꺼짐·잠금화면 컨트롤·대기열) |
| 2차 | F-11~F-12, F-20~F-27, F-31 (홈/채널 탐색, 로컬 개인화, Takeout 가져오기, 오프라인 저장) |
| 3차 | F-28~F-30, F-40~F-41 (배속 기억, 구간 북마크, 백업/복원, PIP, SponsorBlock) |

## 8. 리스크 및 주의사항

- R-01 유튜브 서버 규격(스트림 서명 등) 변경 시 추출 라이브러리 업데이트 전까지 재생이 일시 중단될 수 있음 → 라이브러리 버전 관리·교체 용이 구조로 완화
- R-02 비공식 클라이언트는 IP 단위 봇 확인(429)이 드물게 발생 가능 → 요청 빈도 제어로 완화 (로그인 미사용이므로 계정 위험은 없음)

## 9. Q&A 결정 사항 기록

| 질의 | 결정 |
|---|---|
| 타깃 플랫폼 | Android 전용 |
| 사용 목적/배포 | 개인용, APK 직접 설치 |
| 비공식 추출 허용 | 허용 (개인용 확정에 따라 자동 결정) |
| 앱 범위 | 유튜브 앱과 동일한 사용감의 풀 클라이언트 지향 |
| 로그인 | 배제. 쿠키 방식(WebView/브라우저 쿠키 가져오기)도 위험 동일함을 확인 후 배제 확정 |
| 개인화 방식 | 시청기록·즐겨찾기·구독 등 전부 앱 로컬 구현 |
| 광고 제거 | 별도 기능 아닌 기본 특성으로 포함. 영상 내 스폰서 구간은 SponsorBlock(3차)로 대응 |
| 계정 데이터 이전 | Google Takeout 파일 가져오기, 2차 단계에 구현. 실시간 계정 동기화는 로그인 필요라 제외 |
| 개발 방식 | 1차 MVP → 2차 → 3차 단계적 진행 |
| 지원 기기 | 갤럭시 S20 ~ 최신 기종 (minSdk 29) |
