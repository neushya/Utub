## 실행 방식 조정 (2026-08-17, 구현 중 업데이트)

구현 과정에서 다음 케이스는 **단위테스트가 아닌 통합테스트(5단계, 실기기)에서 검증**하는 것으로 조정한다:

| ID | 사유 |
|---|---|
| TC-EXT-01~04 | 실제 유튜브 서버 응답이 필요 (NewPipeExtractor 실통신). 단위 수준에서는 예외 매핑·모델 변환 로직만 검증되고, 실추출은 통합테스트 시나리오로 확인 |
| TC-PB-09/10 | onTaskRemoved는 Android 서비스 수명주기 — 실기기에서 최근앱 스와이프로 검증 |
| TC-PB-11/12/13 | 오디오 포커스·becomingNoisy는 Media3 내장 처리(설정으로 활성화) — 실기기에서 전화 수신·이어폰 분리로 검증 |
| TC-PB-15 | 모드 전환 위치 유지는 서비스+플레이어 결합 동작 — 실기기 검증 |

대신 단위 레벨에서 추가된 보완 테스트: 재생 상태 스냅샷 저장/복원(DaosTest), 검색 기록 저장 검증(SearchViewModelTest), 클립보드 감지 설정 끔 케이스(HomeViewModelTest), 파서 확장 케이스(모바일/뮤직 도메인, embed, 재생목록 단독).
