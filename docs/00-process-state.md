- **agy 제약**: agy는 headless 모드에서 파일 읽기 권한이 없음 → 문서 내용을 프롬프트에 인라인으로 전달해야 함. 이때 내용의 큰따옴표(")를 작은따옴표로 치환할 것(명령행 인자 깨짐 방지).
