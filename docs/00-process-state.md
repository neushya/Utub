## 주요 방향 전환 이력 (통합테스트 중)

- **하이브리드 전환**: 자체 네이티브 홈/검색 → 유튜브 웹 WebView 탐색 (memory [[utub-hybrid-pivot]])
- **방식 A→B 재전환**: watch 페이지 임베드(방식 A) 폐기 → 영상 클릭 시 네이티브 상세화면 전환(방식 B). 영상 중복·웹 잔존 문제 원천 해결
- **대기열 자동정리**: playNow가 대기열 새로 시작 (누적 방지)
- **UI 개선**: 플레이어 컨트롤 컴팩트화(리스트 확대), 진행바 3dp
- **앱 아이콘**: 홀로그램 유리 UT 로고 적용

## 참고

- **agy 제약**: agy는 headless 모드에서 파일 읽기 권한이 없음 → 문서 내용을 프롬프트에 인라인으로 전달해야 함. 이때 내용의 큰따옴표(")를 작은따옴표로 치환할 것(명령행 인자 깨짐 방지).
- agy 대화 컨텍스트: 1~2단계를 한 대화(-c)로 이어왔고, agy는 01·02·03 문서 전문을 이미 컨텍스트에 보유함. 3단계도 -c로 이어가면 문서 재전달 불필요.
