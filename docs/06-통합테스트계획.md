## A. MVP 핵심 완료 기준 (P1)

| ID | 목적 | 절차 | 기대 결과 | 방식 |
|---|---|---|---|---|
| IT-MVP-01 | 공유(ACTION_SEND) 즉시 재생 | adb로 SEND 인텐트 발사 | 플레이어 열림, 광고 없이 재생 시작 | adb |
| IT-MVP-02 | 링크 탭(ACTION_VIEW) + 타임스탬프 | VIEW 인텐트 `?t=30s` | 30초 지점부터 재생 | adb |
| IT-MVP-03 | 화면 꺼짐 1시간 연속 재생 | 긴 영상 재생 → keyevent 26 → 주기 관찰 | 끊김 없음, 서비스 유지 | adb+타이머 |
| IT-MVP-04 | One UI 딥슬립(Doze) 내구성 | 재생 중 `deviceidle force-idle` → 5분 | 재생 지속 | adb |
| IT-MVP-05 | 잠금화면 컨트롤러 제어·X 종료 | 잠금화면에서 일시정지/다음/X | 즉시 반응, X 시 완전 종료 | 수동 |

## E. 기능 시나리오 (Claude 추가분)

| ID | 목적 | 절차 | 기대 결과 | 방식 |
|---|---|---|---|---|
| IT-FUN-01 | 첫 실행 온보딩 | 신규 설치 후 실행 | 알림→배터리 예외 2장 플로우, 거부 시 홈 배너 | 수동 |
| IT-FUN-02 | 클립보드 감지 칩 (TC-UI-02) | 링크 복사 → 앱 진입 | 칩 노출 → 탭 시 재생, 닫으면 재노출 없음 | 수동 |
| IT-FUN-03 | 최근 재생·이어보기 | 재생 중단 → 홈 → 항목 탭 | 중단 지점부터 이어 재생 | 수동 |
| IT-FUN-04 | 대기열 복원 (TC-PB-18) | 대기열 3곡 구성 → 앱 강제 종료 → 재실행 | 목록·순서 복원 (자동 재생 안 함) | adb+수동 |
| IT-FUN-05 | 백그라운드 모드 3종 (TC-PB-16) | 설정 변경 후 각각 화면 끄기 | 항상=유지 / 끔=정지 / 이어폰=연결 시만 유지 | 수동 |
| IT-FUN-06 | 연관 영상 자동재생 (TC-PB-07) | 짧은 영상 끝까지 재생 | 연관 영상 자동 이어 재생, 설정 끔 시 정지 | 수동 |
| IT-FUN-07 | 배속 변경 | 1.5x 설정 | 속도 변경, 음정 유지 | 수동 |
| IT-FUN-08 | 미니↔전체 플레이어 전환 | 미니 탭→전체, 접기→미니 | 재생 끊김 없이 전환 | 수동 |

## 실행 순서

1. adb 연결 확인 → release APK 설치
2. 자동화 가능 항목 우선 실행 (IT-MVP-01/02/04, IT-EXT-02/04)
3. 수동 항목: 사용자에게 조작 안내 → 결과 확인 (Claude가 logcat·dumpsys로 교차 확인)
4. IT-MVP-03(1시간)은 마지막에 백그라운드로 진행
5. 실패 항목: 원인 분석 → 수정 → 재테스트 → docs/07에 기록
