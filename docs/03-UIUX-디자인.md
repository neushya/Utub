## 1. 스타일 방향

- **컨셉**: 기존 유튜브 앱과 동일한 사용감 (학습 비용 0 목표). 시각 요소는 유사하되 상표 요소(로고 등)는 자체 제작
- **테마**: 다크 테마 기본 + 라이트 테마 지원 (시스템 설정 따름)
- **컬러**:
  - 배경: 다크 `#0F0F0F` / 라이트 `#FFFFFF` (유튜브 앱과 동일 계열)
  - 강조(포인트): 레드 `#FF0033` 계열 (재생 진행바, 활성 탭, 구독 버튼)
  - 텍스트: 다크 `#F1F1F1`/`#AAAAAA`, 라이트 `#0F0F0F`/`#606060`
- **타이포**: 시스템 기본(Roboto). 제목 14~16sp Medium, 부가정보 12sp Regular
- **컴포넌트**: Material 3 기반 + 유튜브 스타일 커스텀 (Jetpack Compose)
- **아이콘**: Material Symbols (outlined)

## 2. 공통 컴포넌트

| 컴포넌트 | 구성 |
|---|---|
| VideoCard (세로 리스트용) | 좌 썸네일(16:9, 재생시간 뱃지, 시청 진행바) + 우 제목 2줄·채널명·조회수·업로드일 + 더보기(⋮) |
| 더보기 시트(⋮) | 다음에 재생 / 대기열에 추가 / 나중에 보기(2차) / 재생목록에 저장(2차) / 오디오로 재생 / 채널 이동(2차) / 공유 |
| ChannelChip | 원형 아바타 + 채널명 |
| MiniPlayer | 높이 64dp: 썸네일(16:9) · 제목/채널 1줄 · 재생/일시정지 · X (버튼 간격 8dp 이상, 오터치 방지). 상단 1.5dp 진행바. **좌·우 스와이프로 종료**(아래 방향은 OS 제스처와 충돌) |
| EmptyState | 일러스트 아이콘 + 설명 1줄 + 액션 버튼 (예: "검색으로 시작해 보세요") |
| ErrorState | 원인 문구 + [다시 시도] 버튼 (추출 실패/네트워크 구분 표기) |
| LoadingState | 스켈레톤 UI (썸네일·텍스트 자리 회색 블록) |

## 3. 화면별 레이아웃

### SCR-000 권한 온보딩 (1차)
2장 페이저: ① 알림 권한 — "잠금화면 컨트롤에 필요해요" → 시스템 다이얼로그 ② 배터리 예외 — "화면을 꺼도 끊기지 않게 해줘요" → 시스템 설정 이동 버튼. 각 장 [허용하기] / [나중에]. 완료 후 간이 홈 진입. 거부 시 홈 상단에 노란 경고 배너("재생이 끊길 수 있어요 → 설정").

- **영구 거부 처리 (Android 13+)**: 권한이 2회 거부되어 시스템 다이얼로그가 더 이상 뜨지 않는 상태면, [허용하기] 탭 시 앱 설정 화면(ACTION_APPLICATION_DETAILS_SETTINGS)으로 직접 이동시키고 이동 전 안내 문구 표시.

### SCR-010 간이 홈 (1차, MVP 전용)
```
┌──────────────────────────┐
│ UTub            🔍   ⚙   │
├──────────────────────────┤
│ ┌──────────────────────┐ │
│ │ 🔍 검색 또는 링크 붙여넣기│ │  ← 탭하면 SCR-200, 링크 감지 시 즉시 재생
│ └──────────────────────┘ │
│ 최근 재생                  │
│ [VideoCard]              │
│ [VideoCard]              │
│  (비어 있으면 EmptyState)   │
├──────────────────────────┤
│ [MiniPlayer (재생 중일 때)] │
└──────────────────────────┘
```
2차에서 SCR-100 정식 홈 피드로 교체되고 하단 3탭 활성화.

- **클립보드 링크 감지**: 앱 진입 시 클립보드에 유튜브 링크(youtu.be, youtube.com/watch 등)가 있으면 검색창 아래에 `[📋 복사한 링크 재생]` 칩을 노출해 1탭 재생 지원. (Android 12+는 클립보드 접근 시 시스템 토스트가 표시됨을 감안, 설정에서 끌 수 있음 — 기본 켬)

### SCR-110 공유 수신 (1차)
- 유튜브 앱/브라우저에서 공유 → UTub 선택 시, 앱 전체 UI를 거치지 않고 **SCR-300 전체 플레이어가 즉시 슬라이드 업**되며 영상 영역에 로딩 스켈레톤 표시 → 추출 완료 즉시 자동 재생.
- 추출 실패 시 플레이어 내 ErrorState 표시([다시 시도] 포함), 사용자가 닫으면 이전 앱으로 복귀.

### SCR-200 검색 (1차)
- 진입 시 키보드 자동 표시, 최근 검색어 목록(개별 삭제 + 헤더 우측 [모두 지우기])
- 입력 중: 자동완성 목록(탭하면 즉시 검색)
- 결과: VideoCard 무한 스크롤, 상단 필터 칩(전체/동영상/채널/재생목록 — 채널·재생목록 결과는 2차)
- 각 카드 ⋮ → 더보기 시트

### SCR-300 전체 플레이어 (1차)
```
┌──────────────────────────┐
│ ▼(접기)                ⋮  │
│ ┌──────────────────────┐ │
│ │   영상 (16:9)          │ │ ← 오디오 모드: 앨범아트+블러 배경
│ │  ◀10  ⏯  10▶          │ │ ← 탭하면 컨트롤 오버레이 (3초 후 숨김)
│ │ ──●───────── 3:21/12:40│ │
│ └──────────────────────┘ │
│ 제목 (2줄)                 │
│ 채널명 · 조회수 · 날짜        │
│ [🎧오디오] [1.0x] [CC] [HD]│ ← 모드/배속/자막/화질 칩
│ [👍(2차)] [나중에(2차)] [공유]│
├─ 다음 재생 ────────────────┤
│ 대기열 ▸ (가로 펼침/세로 시트) │
│ 연관 영상                   │
│ [VideoCard] ...           │
└──────────────────────────┘
```
- 아래로 스와이프 → 미니플레이어로 축소. 가로 회전/전체화면 버튼 → 몰입 모드
- 배속: 0.5~2.0x (0.25 단위). 화질: 자동/144p~최고 (오디오 모드 시 비활성)
- 오디오 전용 모드에서는 자막(CC)·화질(HD) 칩 모두 비활성(Dimmed) — 화면을 보지 않는 용도이므로
- 컨트롤 오버레이: 중앙 ⏯, 좌우 더블탭 10초 이동(유튜브 제스처 동일)

### SCR-320 재생 대기열 (1차)
전체 플레이어에서 "대기열" 탭 → 하단 시트. 현재 곡 상단 고정, 이후 목록 드래그 핸들로 순서 변경, 좌스와이프 삭제. 상단에 셔플·반복(끔/전체/한곡) 토글, "자동재생" 스위치.

### SCR-700 설정 최소판 (1차)
- 재생: 백그라운드 재생 모드(항상/이어폰 시/끔), 연관 영상 자동재생(켬/끔), 기본 재생 모드(비디오/오디오)
- 권한: 알림·배터리 예외 상태 표시 + 재설정 이동
- 취침 타이머: 끔/15/30/60분/현재 영상까지
- 정보: 버전, 오픈소스 라이선스

### SCR-800 알림·잠금화면 (1차)
MediaStyle 표준: 앨범아트 + 제목/채널 + [이전][⏯][다음] + 탐색 시크바 + **[X 닫기]**. 잠금화면·블루투스·워치에 동일 세션 노출.

### SCR-100 홈 피드 (2차)
상단 카테고리 칩(전체/음악/게임/뉴스…) + VideoCard 피드(인기/급상승 기반) 무한 스크롤. 당겨서 새로고침.

### SCR-400 구독 탭 (2차)
상단 구독 채널 아바타 가로 스크롤(탭하면 채널 필터) + 새 영상 통합 타임라인. 우상단 "전체 채널 관리".

### SCR-500 보관함 (2차)
섹션 리스트: 시청 기록(가로 스크롤+전체 보기) / 나중에 보기 / 좋아요 표시 / 내 재생목록(+새로 만들기) / 다운로드. 각 항목 → 상세 리스트 화면(SCR-510/520 등).

### SCR-600 채널 상세 (2차)
배너 + 아바타/채널명/구독자 수 + [구독] 토글(로컬) + 탭(동영상/재생목록) + 정렬(최신순/인기순).

### SCR-720 Takeout 가져오기 (2차)
[파일 선택] → 미리보기(감지된 채널 N개) → [가져오기 시작] → 진행률 바(n/N, 남은 예상시간) → 완료 요약(성공/실패/중복). 진행 중 취소 가능.

## 4. 상태·에러 화면 정책

| 상황 | 표시 |
|---|---|
| 스트림 추출 실패 | 플레이어에 ErrorState: "재생 정보를 가져오지 못했어요" + [다시 시도]. 3회 실패 시 "유튜브 규격 변경 가능성 — 앱 업데이트 필요할 수 있음" 안내 |
| 네트워크 없음 | 전역 스낵바 + 다운로드 항목만 재생 가능 표시 (2차) |
| 요청 제한(429) | "잠시 후 다시 시도해 주세요" + 자동 재시도 카운트다운 |
| 연령 제한/비공개/삭제 영상 | 카드·플레이어에 사유 명시 ("이 영상은 재생할 수 없어요: 비공개") |
| 로딩 | 스켈레톤 UI (스피너 최소화) |
| 배터리 예외 미설정 | 홈 상단 경고 배너 (닫기 가능, 설정에서 재표시) |

### 오디오 포커스 정책 (1차, agy 검토 반영)

| 상황 | 동작 |
|---|---|
| 전화 수신 등 일시적 포커스 상실 | 즉시 일시정지 → 종료 시 자동 재개 |
| 내비 안내·짧은 알림음 (덕킹 허용) | 볼륨을 일시적으로 30%로 낮췄다가 자동 복원 |
| 다른 미디어 앱이 재생 시작 (영구 상실) | 일시정지 (자동 재개 안 함) |

### 2·3차 화면 상세 스코프
SCR-510(재생목록 상세)·SCR-520(다운로드 관리)·SCR-330(구간 북마크)의 상세 와이어프레임은 해당 단계 착수 시 본 문서에 추가한다 (현 시점은 구성 요소 정의까지만).

## 5. 인터랙션·모션

- 미니플레이어 ↔ 전체 플레이어: 드래그 연동 전환(유튜브 앱과 동일한 continuous gesture)
- 화면 전환: 표준 슬라이드/페이드 200ms
- 대기열 항목: 드래그 앤 드롭 + 스와이프 삭제 시 실행취소 스낵바
- 더블탭 시크: 좌/우 반원 리플 + "10초" 표시
- 햅틱: 드래그 시작/구독 토글 시 약한 진동

## 6. 접근성

- 모든 컨트롤에 contentDescription, 최소 터치 타깃 48dp
- 자막(CC) 토글 제공, 시스템 글꼴 크기 반영
